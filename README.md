# NOTHING - AP DSC SA Telugu Practice Portal

**NOTHING** is a web-based mock test platform tailored specifically for candidates preparing for the **AP DSC (School Assistant - Telugu)** competitive examination.

---

## 🚀 Features

- 📝 **Exam-Style Interface:** Questions loaded one by one with smooth Next/Previous navigation.
- 📌 **Question Palette Grid:** Quick navigation tracking Answered, Unanswered, and Flagged (Marked for Review) questions.
- ⏱️ **Active Countdown Timer:** Live time tracking with dynamic color warnings and alert sounds.
- 🌓 **Dark Mode Support:** Clean blue-and-white theme with a single-click dark mode toggle for comfortable studying.
- 📊 **Detailed Answer Breakdown:** Post-test performance summary with correct choices, user selections, and explanations in Telugu.
- 💾 **Local Storage Integration:** Automatically saves past attempt history and score trends locally.
- 🖨️ **Printable Result Summary:** Easily export or print test summaries for review.
- 📱 **Mobile Friendly:** Fully responsive design optimized for smartphones, tablets, and desktops.

---

## 🛠️ Tech Stack

- **HTML5** – Page Structure & Accessibility
- **CSS3** – Responsive Styling, Custom CSS Variables & Animations
- **JavaScript (ES6+)** – Quiz Logic, Timer Engine, State Management & Web Audio API
